Historical documents from the **original six-scenario** AMS tabletop demo
(`/Users/alanlands/Documents/sixFold`), kept for background only.

They describe S1–S6, a 90-minute six-scenario run order, and a build schedule
around a Jul 2026 date. **None of that is this project's scope.** This repo
builds S3 (Enhancement Delivery) only — see `CLAUDE.md` and the root
`README.md` for what is actually true today.

Read these for the reasoning behind S3's original acceptance criteria; do not
read them as a plan, a file map, or a statement of current scope.

- `SCENARIOS.md` — capability decomposition for all six scenarios
- `BUILD_PLAN.md` — day-by-day build plan and the six-scenario demo flow

The guardrails

How it is kept safe — by design, not by promise

Assurance · enforced controlsTechnical boundaries make the workflow auditable and repeatable.07 / 07

A narrow blast radius

AI may only edit an approved list of files. The impact analysis it must read — it cannot edit.

An independent check

The regression suite is human-owned. AI has no write path to it — so passing it means something.

Separation of duties

The tester cannot generate code; the developer cannot approve their own tests. Enforced by role, not policy.

Derived, not drafted

Deploy order comes from the service dependency graph. Cross-team tickets are raised only where code must change.

Honest paperwork

The release record lists what this run did not prove — unevidenced claims are stated, never hidden.

Server-side gates

Commit is blocked until tests and regression really passed — read from the event log, never asserted by the screen.

Every gate is enforced by the server, not the screen — a client cannot assert its way past one.

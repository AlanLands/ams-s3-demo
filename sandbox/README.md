# sandbox/

Ad-hoc demo and testing projects that are **not part of the S3 Enhancement codebase**.
Nothing in here is imported by the S3 pipeline, API, frontend, or tests.

- `spring-demo/` — two Spring Boot 3 apps (policy-service :8081, claims-service :8082)
  showing service-to-service REST calls with synthetic MapleSure data. See its README
  for the run/demo script.
- `callToday/` — scratch files.
